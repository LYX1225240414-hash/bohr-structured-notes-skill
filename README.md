# 文献结构化笔记 Skill：章节对齐 · 字段齐备 · 锚点可回链

玻尔科学空间高校挑战赛 · 北京化工大学分站赛 作品。

把论文转化为能继续用、能复核、能检索的结构化笔记。核心三层：章节对齐 → 字段化抽取 → 锚点回链。每条笔记含 field/claim/evidence/anchor/confidence，覆盖研究问题、方法、数据、结果、结论、限制。

## 目录
- SKILL.md：6 步工作流
- resources/checklist.md：自检清单
- resources/field_dict.md：字段字典
- resources/output_example.json：输出结构示意（非答案）
- examples/README.md：最小调用示例
- run/paper_input.txt：真实论文片段输入
- run/result.json：真实试跑结果（3 章 7 条笔记，partial 状态演示）

## 试跑说明
run/ 基于 arXiv:2011.03269v1 摘要片段，仅展示工作流，非正式案例答案。

仅供赛事评审与学习交流。

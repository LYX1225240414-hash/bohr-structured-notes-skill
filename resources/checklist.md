# 结构化笔记自检清单

## 章节完整
- [ ] section 数量与原文真实标题数一致
- [ ] 无漏章漏段，双栏论文已按阅读顺序重排
- [ ] 每条笔记归属到正确章节

## 字段覆盖
- [ ] research_question / motivation 已抽取
- [ ] method / dataset / metric 已抽取
- [ ] result / conclusion 已抽取
- [ ] limitation 已抽取（原文未述则明确标注）
- [ ] reproduce_info（可复现条件）已抽取或标注缺失

## 锚点可回链
- [ ] 每条笔记都有 anchor
- [ ] anchor 格式符合 p<页>:<段> / <章节>:<段> / fig|tab|eq<号>
- [ ] 抽查每条 anchor 能回到原文对应位置
- [ ] 数值与变量的 evidence 短引与 anchor 位置一致

## 事实一致
- [ ] 数值、单位、变量、实验条件原样保留
- [ ] 因果/相关、限定词、否定关系未改变
- [ ] 未添加原文外信息
- [ ] 术语跨章节统一，原写法保留在 notes

## 可核验性
- [ ] status 与实际完成一致
- [ ] 无法判断/材料缺失写入 uncertainties
- [ ] change_log 记录自检回修
